# Tarea1_PDI
Pictionary Cam - Guía de uso

Bienvenido a Pictionary Cam, un divertido juego de dibujo con cámara. Usa un objeto rojo para dibujar en el aire y desafía a tus amigos a adivinar la palabra.

INSTRUCCIONES DE JUEGO:

1. Ejecuta el programa y permite que la cámara se active.
2. El Jugador 1 escribe una palabra secreta en el campo “Palabra secreta” y presiona “Fijar palabra”.
3. El Jugador 1 presiona “Iniciar dibujo” y usa un objeto rojo (por ejemplo, una tapa o marcador) para dibujar la palabra en el aire frente a la cámara.
4. El dibujo aparecerá en la pantalla, sobre la imagen de la cámara.
5. Cuando el Jugador 1 termine, presiona “Detener dibujo”. La cámara se congela.
6. El Jugador 2 escribe su intento en el campo “Adivina” y presiona “Intentar”.
7. Si acierta, el sistema mostrará un mensaje de felicitación. Si no, podrá intentarlo de nuevo.
8. Al finalizar la ronda, presiona “Siguiente palabra” para jugar otra vez.

FUNCIONES ADICIONALES:
- “Limpiar pizarra”: borra todo el dibujo actual.
- “Reanudar cámara”: vuelve a activar la cámara después de congelarla.
- El juego incluye un temporizador de 60 segundos por ronda. Si el tiempo se acaba, la palabra se revela automáticamente.

REQUISITOS:
- Cámara web activa.
- Buena iluminación para detectar correctamente el color rojo.
- Un objeto rojo (tapa, marcador, etc.) para dibujar.

¡Disfruta de Pictionary Cam y reta tu creatividad junto a tus amigos!
